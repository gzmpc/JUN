# 清颜计划｜项目计划

## 实现方式
基于固定 Expo Router / React Native / TypeScript / NativeWind 移动模板，先交付可操作的中文手机端原型。第一版采用本地状态模拟数据，突出每日打卡、标准化拍照引导、趋势复盘、医生确认后的用药与就诊记录，并将诊断、开药和疗效承诺排除在产品边界之外。后续接入真实小程序时，照片应进入受控对象存储，记录进入数据库，并增加家长授权、删除和审计能力。

## 页面与模块
- 首页：今日完成度、面部记录入口、红旗提醒、阶段目标、家长支持入口。
- 每日打卡：清洁、保湿、防晒、运动、睡眠、饮食六项；明确“温和清洁、不挤压、不自行加药”。
- 趋势：连续打卡、近7日习惯完成度、照片时间轴；只展示趋势，不给出自动诊断结论。
- 记录：照片说明、医生确认药物、复诊时间、复盘问答和隐私删除边界。

## 设计方向
候选风格：
1. 清透临床感（0.08）：白底、薄荷绿和深墨色，像轻量健康工具。
2. 青少年运动日志（0.06）：更强的蓝紫对比和卡片层级。
3. 温柔家长协作（0.04）：暖米色与珊瑚色，强调陪伴。

选择清透临床感。核心原则是低压力、可执行、非评判；使用薄荷绿作为“完成与修复”的品牌色，珊瑚橙只用于风险提醒；采用纵向信息流和底部四项导航，方便单手操作；照片卡片使用固定比例和拍摄提示建立可比性。动效只使用轻微的进度变化和按钮反馈，不制造医疗焦虑。标题使用系统无衬线粗体，正文使用系统无衬线常规字重，数字进度使用更大字号。

品牌定位：给青少年和家长使用的、把皮肤管理拆成每天一小步的痤疮长期记录工具。关键词：清晰、克制、鼓励。文案示例：“今天只做六件小事，不追求一次变好。” “记录是为了看见变化，不是给自己打分。”

## 医疗与隐私边界
产品全流程提示“不是诊断工具，不能替代皮肤科面诊，任何药物方案必须由医生确认”。严重疼痛、快速加重、结节囊肿、明显瘢痕、发热或心理影响时，建议尽快告知家长并就医。照片默认私密，提供撤回、删除和不上传选项；不使用人脸识别或自动分级。

## 项目结构
`app/(tabs)/` 放四个主屏幕；`components/` 放可复用卡片、进度和提示组件；`constants/` 放颜色与文案；`assets/images/` 放原生品牌图标；后续 `server/` 和 `drizzle/` 接入受控照片存储、用户授权和记录同步。
